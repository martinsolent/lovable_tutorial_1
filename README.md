# Prototype a Mobile App with Lovable

This repository contains a beginner-friendly, step-by-step tutorial for using [Lovable](https://lovable.dev) to build a mobile-first web app, publish it, and try it on a phone as a home-screen app. It is a learning resource, not the source code for the wardrobe app described in the example prompt.

The tutorial takes you through creating a free Lovable account, writing a useful app prompt, reviewing and refining the preview, checking credits, publishing the site, and sharing it with testers. It also explains how to add the published site to an Android or iPhone home screen and update it after making changes.

## Get started

Open [`index.html`](./index.html) in a browser to use the interactive tutorial. It includes:

- 19 illustrated steps, with progress tracking and a table of contents
- An overview video with English captions
- Step narration, using browser speech when a recording is not available
- A sample prompt for building a four-screen wardrobe organizer called **Closet**
- Follow-up guidance, iPhone instructions, troubleshooting, and links to Lovable documentation

No build step or package installation is required.

## What you will need

- A Lovable account
- A simple app idea (the guide uses a wardrobe organizer)
- A phone with Chrome on Android or Safari on iPhone, if you want to test the published prototype on a device

The app built during the tutorial is a web app, not a native mobile app. The home-screen shortcut is for testing; it does not create an app-store listing.
